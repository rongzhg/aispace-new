## 1. Chat（统一对话入口 / 平台 Copilot）

**定位**：平台级 copilot 入口。默认接后端常驻「通用 Agent」，用自然语言直接驱动平台操作（列出/创建/发布 Agent、建项目空间、提交需求等），并可用 `/` 进入内置技能（Agent Creator / Skill Creator）。
**对应 spec**：[L-assistant.md](./specs/L-assistant.md)（会话契约见 [M-agent-api.md](./specs/M-agent-api.md)）。
**实现**：`components.tsx · ChatPanel`（~1341–1648）、`GENERAL_INTRO`/`CHAT_SKILLS`。

### 重点功能列表

**会话轨（左侧侧栏）**
- ✅ 新建 / 切换 / 重命名（弹窗，≤60 字）/ 删除（二次确认）会话
- ✅ 每条会话显示标题、更新时间、消息条数；顶部显示会话总数
- ✅ 侧栏可收起/展开（收起态仅留「展开」「新建会话」两个图标按钮）
- ✅ 历史落库：copilot 路径后端每轮原子落库；轻量模式前端 `PUT /api/copilot/sessions/{id}` 兜底；首条用户消息前 24 字自动作标题

**对话与执行**
- ✅ 「通用 Agent」开关（默认开）：开 → 接后端常驻 Agent 真执行；关 → 前端轻量正则意图匹配
- ✅ 连接态徽标：轮询 `/api/copilot/status`（4s）显示「已连接 / 待启动 / 未连后端」
- ✅ SSE 流式回复（`POST /api/copilot/chat/stream`，事件 `delta`/`done`/`error`）：逐字增量、首 token 前「思考中…」、出错转红气泡
- ✅ 消息渲染：系统提示居中、用户蓝气泡右对齐、助手灰气泡左对齐、错误红气泡，气泡下带 HH:mm 时间戳
- ✅ 空状态：标题「从一个明确动作开始」+ 四条可点击建议（点击填入输入框）

**Slash 内置技能**
- ✅ 输入 `/` 弹出技能菜单（`CHAT_SKILLS`：`/agent-creator`、`/skill-creator`），按子串过滤；未知命令给出可用项提示
- ✅ 进入技能后显示当前技能 chip + 「× 退出」回到通用 Agent
- ✅ **Agent Creator**：解析「名称：职责」→ 调 `/api/agents` 创建（默认 Claude Code / claude-opus-4-8 / temp 0.7 / max_tokens 4096，角色写入 claude.md），回报版本号
- 🔸 **Skill Creator**：生成技能草稿（名称/描述/触发/步骤），demo 不持久化

**轻量模式（关开关时，前端本地编排）**
- ✅ 正则识别意图：列出 Agent、列出已发布、创建 Agent、创建项目空间（仅管理员）、帮助；操作后刷新列表
- 🔸 `!API_ON` 时提示「需先在本机启动后端才能真正执行操作」

> **差异提示**：spec 中的 `requirement-clarify / submit_requirement`（需求澄清闭环）属后端 copilot skill 行为，前端无对应分支（消息直接透传 SSE）→ 标 ❓待后端验证。Chat 内的创建/操作当前**无二次确认拦截**（仅删除会话有 Popconfirm）。

## 2. Agent（Agent 注册表 + 工作台 + 版本）

**定位**：Agent 全生命周期主控台。围绕 Owner / Live 运行态 / Draft 草稿态做运营判断；进入工作台完成创建、配置、试跑、发布、版本回滚。
**对应 spec**：[A-agent-lifecycle.md](./specs/A-agent-lifecycle.md)、[B-framework-config.md](./specs/B-framework-config.md)、[C-model-config.md](./specs/C-model-config.md)、[F-version.md](./specs/F-version.md)、[G-config-preview.md](./specs/G-config-preview.md)、[H-permission.md](./specs/H-permission.md)（发布/运行语义见 [I-runtime-publish.md](./specs/I-runtime-publish.md)）。
**实现**：`App.tsx`（列表/筛选/状态）、`components.tsx · AgentWorkbench / AgentDetail / VersionDiff / VersionHistory / PublishChooser / PublishModal / AssetDrawer / DebugPanel`。

### 重点功能列表

**列表（Agent Operations / Registry）**
- ✅ 高密度运营表，四列状态：**Agent**（名称+id+框架+更新时间）、**Owner**（创建人）、**Live**（运行态：未发布/部署中/失败/运行中/已停止 + Live 版本 + 部署方式 L1/L2/L3 + 本地/云端）、**Draft**（Head 与 Live 关系：仅草稿/与 Live 一致/与 Live 不同）
- ✅ 搜索（**仅按名称**匹配，占位文案写「名称或描述」）、创建人过滤、Live 状态过滤、「Draft 与 Live 不同」过滤、排序（最近编辑 / 名称 A-Z）
- ✅ 「显示 N / 总数」计数、刷新、空状态引导、删除二次确认（软删除，记录保留）
- ✅ 部署中服务每 5s 轮询自动刷新运行态
- ✅ 进入工作台仅经行内「管理」按钮（整行不可点）；顶部无聚合 KPI 概览条（已移除）

**创建 / 编辑（AgentWorkbench，create/open/detail 共用）**
- ✅ 双栏工作台：左栏元信息条 + 指令文件编辑器 + 能力绑定；右栏「线上发布与运行」+「试跑」常驻
- ✅ 框架选择（仅创建态可选；Claude Code、OpenClaw 可用，Custom「coming soon」、Hermes 禁用），打开已有 Agent 时框架/名称只读
- ✅ 模型按供应商分组选择（Anthropic / OpenAI / DashScope百炼 / AISpace-伏渊），必填校验（未选禁用保存）
- ✅ 模型参数 Popover：Temperature(0–1) + Max Tokens(256–32000)，数据驱动渲染（元信息为前端常量 `MODEL_PARAMS`）
- ✅ 指令文件框架差异化：Claude Code 单文件 `claude.md`；OpenClaw 三 Tab `role/agent/user`（有内容显蓝点）；「重置为模板」
- ✅ 工具/技能经 `AssetDrawer` 抽屉绑定（搜索、按来源分区、计数确认）
- ✅ 创建主操作「创建 Agent」→ 生成 v1 并停留工作台；编辑「保存为新版本」（无变更禁用）

**版本（Head / Live / Runtime 三层）**
- ✅ 右栏明示 Head / Live / Runtime 关系，Head≠Live 或有未保存改动时文字提示
- ✅ 「版本与回滚」抽屉（`VersionHistory`）：版本列表（最新/已发布徽章）+ 明细只读 + 版本对比 Tab
- ✅ 「回滚为新版本」（载入编辑器）/「直接发布 vN」（改 Live 指向，已是 Live 则禁用）
- ✅ 独立版本对比页（`VersionDiff`）：字段级差异 + 配置文件逐行 LCS diff，默认次新 vs 最新
- ✅ 版本快照结构 `{version, createdAt, config}`；无变更不生成新版本

**试跑（DebugPanel，右栏常驻）**
- ✅ 有运行实例时「当前配置 / 线上服务」切换；mock 态本地模拟回复，连后端走协议1(JSON)/协议2(SSE)

**发布入口**
- ✅ 右栏「线上发布与运行」承载发布/启动/停服/重新发布；`PublishChooser` 选版本 + 运行环境（L1/L2/L3），`PublishModal` 给稳定 API 调用示例（详细发布/运行语义见 spec I）

**权限消费**
- 🔸 `AssetDrawer` 锁定态 UI 完整（置灰+锁图标+Tooltip+禁选），但当前数据流 `locked` 硬编码 false，运行时不产出锁定项

> **差异提示**：① **配置预览/导出在主工作台未实现**（仅未路由的旧组件 `AgentBuilder` 有 JSON/YAML 预览参考实现）→ spec G 整体回退为 ⬜后续；② 锁定态有 UI 无数据；③ 列表搜索只匹配名称；④ 模型参数为前端常量、不随模型切换变化；⑤ 未保存改动离开**无二次确认**、前端无重名校验；⑥ 指令编辑器为 Ant Design `Input.TextArea`（等宽+autoSize），**无 Markdown 高亮/行号**；⑦ 模板内联于 `config.ts` 的 `TEMPLATES`（`产品文档/templates/` 目录不存在）。

## 3. Playground（与已发布 Agent 对话）

**定位**：与**已发布** Agent 的对话试验场，接入统一 Session API（服务端有状态、事件驱动），带多会话侧栏与运行态徽标。
**对应 spec**：[I-runtime-publish.md](./specs/I-runtime-publish.md)（Playground 章节）+ [M-agent-api.md](./specs/M-agent-api.md)（Session 契约）。
**实现**：`components.tsx · Playground`（~1170–1334）复用 `DebugPanel`。

### 重点功能列表

**对象与进入**
- ✅ 仅列出**已发布** Agent（`GET /api/published`；mock 模式降级用传入列表）
- ✅ 进入即用：挂载时默认选中第一个已发布 Agent 并自动开聊（`initedRef` 防 StrictMode 双跑）
- ✅ Agent 选择器：下拉展示 名称 + 版本码片 `vN` + 框架 Tag + 模型；列表为空时不渲染选择器
- ✅ 取该已发布版本的 config 喂对话（`GET /api/agents/{id}` → `versions.find(version)`）
- ✅ 无已发布 Agent 时空状态引导「去详情/编辑页点发布」

**会话（统一 Session API）**
- ✅ 多会话侧栏：列表 / 详情回显 / 新建 / 删除（`/api/sessions` 四端点），显示标题/时间/消息数、active 高亮、Popconfirm 删除
- ✅ 自动会话装载：选中 Agent 后有会话则打开最近一条并回显，无则自动新建（建会话即确保云端沙箱就绪）
- ✅ 空会话复用 + 并发去重（`reuseEmpty` 复用 count=0 会话；`creatingRef` 防连点重复建）
- ✅ 删除自愈：删当前会话后切到剩余最近一条，全删完则重建一条
- ✅ 会话侧栏可收起（`pgRailCollapsed`）

**对话引擎与运行态**
- ✅ 绑定会话时走 `POST /api/sessions/{id}/events[/stream]`（统一 Session，服务端每轮原子落库）；无会话时回退 `service-chat[/stream]`（无状态服务调用）
- ✅ SSE 流式（`delta`/`done`/`error`）：逐字显示 + 打字光标 + 思考点动画
- ✅ 运行态徽标（`GET /api/services`）：隔离级别（`isoName`+L 级）、本地/云端沙箱、运行状态
- 🔸 `embedded` 形态复用同一组件（隐藏页头、压缩选择器）；mock 降级标注「未连后端 · 本地 mock」

> **Playground vs 工作台试跑差异**：Playground 有完整**多会话侧栏 + 统一 Session 回显/增删**，对象限**已发布** Agent，走 `events`（有状态）；工作台试跑无会话侧栏，对象是当前草稿/某保存版本，走 `service-chat`（无状态）。

## 4. 会话（会话控制台 / 创建人视角归集）

**定位**：按「创建人」维度，把我创建的所有 Agent（含 L1/L2/L3 及通用助手）曾经活跃过的全部会话聚合成一个列表，支持检索过滤与明细只读回看。
**对应 spec**：[N-session-console.md](./specs/N-session-console.md) + [M-agent-api.md](./specs/M-agent-api.md)。
**实现**：`components.tsx · SessionConsole`（~2054–2229，文件末）。

### 重点功能列表

**聚合列表**
- ✅ 跨 Agent 聚合：列出「我为创建人」的所有 Agent（含 L1/L2/L3 及通用助手）活跃过的会话（`GET /api/sessions?scope=created&page=&size=20`）
- ✅ 仅创建人可见（页头明示「仅自己创建的可见」）
- ✅ 服务端分页（0-based page + 固定 size=20，`total>20` 才显分页器，显示「a-b / 共 N 条」）
- ✅ 列表列：会话标题(+状态药丸)、所属 Agent、运行环境（`isoName · L? · 本地/云端`）、发起人（非本人加「他人」标记）、轮次（缺省按 ⌈count/2⌉ 估算）、最后活跃时间
- ✅ 工具条「共 N 条（已过滤）」+ 手动刷新（**无自动轮询**）

**检索过滤（三类可组合）**
- ✅ 所属 Agent 下拉（候选来自 `facets.agents` 带计数）、运行环境 Segmented（全部/L1/L2/L3）、标题关键词
- ✅ 关键词 300ms 防抖打服务端（`q`），任一过滤变更回第 1 页

**明细回看（只读）**
- ✅ 点行打开抽屉（`GET /api/sessions/{id}`）：标题/会话 id/状态 + 元数据条（调用版本 `v{n}`、归集来源、创建时间）
- ✅ 对话回看：user/assistant 左右气泡 + 各自时间戳，`sys` 居中，`err` 轮次标「出错」+错误色；底部「只读 · 创建人视角回看」
- ✅ 抽屉宽度可左右拖拽（默认 560px，420 ~ 视口宽-120）

**空状态分支**
- ✅ 未连后端 / 无匹配 / 无会话三种文案；无会话且无过滤时显示「去创建 / 部署 Agent」按钮（跳 Agent Tab）
- 🔸 `!API_ON` 时列表清空、抽屉显「未连接后端」（无前端假数据）

> **差异提示**：明细的「归集来源（网关直连/云端回传）」UI 已就绪，但后端从外部直连/网关旁路把会话回传平台的**投递通道尚未实现**（仅前端展示位）。PlatformAdmin 全局视角、会话归档/状态机为 M Phase 4，未建。

## 5. Skill（技能市场 / 当前空间技能页）

**定位**：当前项目空间的技能管理页 —— 浏览/上传/删除技能、查看技能文件树与内容。技能可在创建/编辑 Agent 时绑定（per-agent 绑定在 `AssetDrawer`，不属本 Tab）。
**对应 spec**：[E-skills.md](./specs/E-skills.md)（共享市场 UI 见 [D-mcp-tools.md](./specs/D-mcp-tools.md)）。
**实现**：`components.tsx · SkillMarket / SkillTreePage`（共享 `MarketCard`）。

### 重点功能列表

**页面与概览**
- ✅ 独立侧栏「Skill」直接挂载 `SkillMarket`（顶部标题 + 副标题说明 + 刷新 + 新建技能）
- ✅ KPI 概览一行：可用技能总数、平台全局数（所有空间共享）、本空间私有数
- ✅ 列表来自 `GET /api/skills?ws=`；空状态（Empty + 新建）/ 加载态（Spin）

**卡片网格（共享 MarketCard）**
- ✅ 每张卡含技能名、技能 id、描述（最多 3 行）、创建人 + 创建时间
- ✅ 右上徽标三态：平台全局→「全局」蓝徽 / 上传包→「N 文件」 / 其它→来源名（custom→自定义）
- ✅ 卡片 meta：技能声明的 `allowed_tools` 以小标签列出
- ✅ 卡片操作：主操作「详情」+ 次级「删除」（平台全局技能只读、不渲染删除）

**上传与删除**
- ✅ 新建技能弹窗：Upload.Dragger 拖拽 .zip/.tar/.tar.gz → multipart `POST /api/market/skills/upload?ws=`；成功 toast 显示技能名/文件数/SKILL.md 路径，失败显示后端 detail
- ✅ 删除走 Popconfirm（「软删除，可重新上传同名恢复」）→ `DELETE /api/skills/{id}?ws=`

**详情（SkillTreePage 独立全页）**
