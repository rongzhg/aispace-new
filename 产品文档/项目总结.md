# AISpace · Agent 平台 — 项目总结

> 截至 2026-06-25。本文件是项目的进展与决策快照，供团队/AI 快速了解全貌。

## 1. 目标

在集团内复制一个「Claude Managed Agent」平台：让用户在平台上创建、配置、调试、版本化管理 AI Agent。配套两个工作目标——团队 AI native 化（全栈 + vibe coding）、需求 T+1 快速交付。

## 2. 工作方法（已确立）

采用 **spec-driven development**：PM 用自然语言 + demo 表达意图，沉淀成统一格式的 spec，全栈开发（的 AI）据 spec + demo 实现，尽量减少口头沟通。关键是先建「共享契约」作为多人/多 AI 协作的地基。

推进顺序：**契约 → 用真实项目（本平台）打磨契约 + 沉淀 demo → 后续再做需求 agent**。

## 4. 关键产品决策（已拍板）

- **框架**：Claude Code（单 `claude.md`）、OpenClaw（`role/agent/user.md` 三文件 Tab）可选；Custom/Hermes 占位禁用。prompt 落点：Claude Code → claude.md；OpenClaw → role.md（人设）+ agent.md（行为）。
- **模型**：所有框架必选模型；按供应商分组（Anthropic / OpenAI / DashScope / AISpace-伏渊 如 yufeng-vl）；清单全平台统一、无权限控制、由接口下发。参数为数据驱动动态表单，定义来自外部接口，本平台不维护。
- **版本**：编辑保存即生成新版本（N+1），无变更禁用保存；Head 是当前最新已保存版本，Live 是线上发布版本；支持**任意两版本对比**（字段级 + 配置文件逐行 diff）。回滚有两种：直接发布历史版本为 Live，或载入历史配置后保存为新 Head。
- **草稿**：本期**不做**，留待后续版本（demo 已移除）。
- **权限**：粒度 = 项目空间 + 角色 + 资产；无权限的工具/技能锁定置灰不可选。
- **组织**：项目空间（Workspace）为权限边界，资产按空间隔离；新用户自带默认空间；可创建/切换空间、管理成员；一个空间可多 Owner（至少一名）。三角色：平台管理员 / 项目管理员(空间 Owner) / 项目成员。
- **登录**：生产对接集团 SSO；demo 免登录 mock 用户。审计：方案已记录，本期不做。
- **创建/编辑交互**：**Agent 工作台 / 双栏 Builder**（左配置：框架/基本/模型/文件/工具技能；右侧常驻线上发布与运行、试跑），不分步。
- **调试/试跑**：工作台右栏「试跑」默认喂当前配置；当 Live 运行中时可切换为「线上服务」。

## 5. 视觉风格（已定）

开发者工具风、浅色高密度、克制。主色 = 墨色 `#17171C`（主按钮），强调 = 靛蓝 `#4F46E5`（仅链接/选中）。1px 发丝描边、6–8px 圆角、控件高度 34、系统字体、模型名/参数用等宽。语义色仅用于状态。详见 `视觉规范.dc.html`。

## 8. 进展日志（截至 2026-06-28）

- 视觉按专业高密度控制台重做：Agent Operations 表格、Owner/Live/Draft 信息架构、双栏 Agent 工作台。
- 文档拆分为 `产品文档/`（开发 vibe coding 主读）与 `技术文档/`。
- **落地 Python 后端**（FastAPI + SQLite）：CRUD/版本/空间成员/发布/调试。
- **前后端打通**：前端自动探测后端，真实读写。
- **调试/试跑改为真实运行**：后端无头调本机 Claude Code（`--append-system-prompt` 注入配置、`--resume` 多轮），失败显示真实报错。
- **发布**：先保存为版本，再选择某个已保存版本作为 Live，并选择部署方式（共享/独立/即用即弃）；发布会启动或替换 Runtime，不隐式保存配置。
- **Playground**：与所有已发布 Agent 的 Live 版本真实对话，并提供会话侧栏。
- 列表显示 Owner、Live 状态、部署方式、Draft(Head/Live 关系) 与管理入口，不展示大模型字段。
- 环境坑记录：需装 Claude Code CLI（`npm i -g @anthropic-ai/claude-code`）；后端找不到 claude 时用 `CLAUDE_BIN` 指定；订阅登录用户勿设 `ANTHROPIC_API_KEY`；公司网络若做 TLS 拦截会导致 claude 连不上 Anthropic（换网络或走百炼/伏渊备选）。
- **发布即起服务**：点发布为该 Agent 启动常驻服务（每 Agent 一进程一端口），暴露 `/chat`、`/chat/stream`；本地单实例（换版本停旧起新，服务记录带 version）。
- **API 三协议**：协议1 一次性 JSON、协议2 SSE 流式（token 级增量，`--include-partial-messages`）、协议3 异步作业（后续）；demo 实现 1+2。Playground 走 SSE 逐字流式。
- **运行服务运维**：Agent Operations/工作台展示单个 Agent Live/Runtime；「部署」控制台集中管理已发布服务；侧栏提供「停止所有 Agent 服务」用于本地清理。
- **Chat 统一入口**：会话轨 + 默认通用 agent + slash 选内置 skill（`/agent-creator`、`/skill-creator`），通用 agent 轻量真执行平台操作。
- **通用 agent 正式路径**：Claude Code + 平台工具（`backend/mcp_server.py` 的 MCP），订阅登录无需 API key（`templates/general-agent/`）。
